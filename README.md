# Дом 1417

PS1-хоррор в браузере: заброшенный особняк культа в Ист-Кливленде. Можно играть одному или вдвоём (у одного камера с ночным режимом, у другого фонарь).

Играть: https://ninjagraph2.github.io/dom1417/

Всё в одном `index.html` на Three.js r128; кооператив работает через WebRTC (PeerJS), библиотеки лежат рядом.
